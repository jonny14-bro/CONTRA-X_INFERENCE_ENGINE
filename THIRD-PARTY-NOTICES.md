## PWEA Unicode compatibility tables

The generated file
`pwea/native/include/pwea_unicode_tables.h` is produced by
`pwea/native/tools/generate_unicode_tables.py`.

Its generation uses:
- Python `unicodedata` version 16.0.0.
- Python package `regex` version 2026.9.10.

The `regex` 2026.9.10 package declares the licence expression
Apache-2.0 AND CNRI-Python and supports Unicode 17.0.0.

Consequently, the generated compatibility table combines properties
derived from Python's Unicode 16.0.0 database and properties supplied
through the `regex` package. It should not be described as a uniform
Unicode 16.0 dataset.

https://pypi.org/project/regex/2026.9.10/
